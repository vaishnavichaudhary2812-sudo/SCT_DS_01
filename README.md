# SCT_DS_01 
# Data Science Internship Projects(SkillCraft Technology)

## Overview

This repository contains four Data Science internship tasks focused on data visualization, exploratory data analysis, machine learning, and accident pattern analysis. The projects were developed using Python and various data science libraries to extract meaningful insights from real-world datasets.

---

## Task 1: Population Distribution Visualization

### Objective

Visualize the distribution of population across countries using the World Bank Population Dataset.

### Tools & Technologies

* Python
* Pandas
* Matplotlib
* Seaborn

### Key Activities

* Data loading and preprocessing
* Population distribution analysis
* Histogram visualization
* Top populated countries analysis

### Outcome

Identified population distribution patterns and compared population sizes across countries using visualizations.

---

## Task 2: Titanic Dataset - Data Cleaning and Exploratory Data Analysis

### Objective

Perform data cleaning and exploratory data analysis to uncover relationships and trends in the Titanic dataset.

### Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

### Key Activities

* Handling missing values
* Data cleaning and preprocessing
* Survival analysis
* Correlation analysis
* Data visualization

### Outcome

Discovered key factors affecting passenger survival, including gender, passenger class, age, and fare.

---

## Task 3: Bank Marketing Prediction using Decision Tree Classifier

### Objective

Build a machine learning model to predict whether a customer will subscribe to a bank term deposit based on demographic and behavioral data.

### Dataset

Bank Marketing Dataset from UCI Machine Learning Repository

### Tools & Technologies

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Seaborn

### Key Activities

* Data preprocessing
* Label encoding
* Model training and testing
* Decision Tree implementation
* Performance evaluation

### Outcome

Developed a Decision Tree Classifier and evaluated model performance using accuracy, confusion matrix, and classification report.

---

## Task 4: Traffic Accident Pattern Analysis

### Objective

Analyze traffic accident data to identify patterns related to weather conditions, road conditions, lighting conditions, and time of day.

### Tools & Technologies

* Python
* Pandas
* Matplotlib
* Seaborn

### Key Activities

* Data cleaning
* Exploratory data analysis
* Weather condition analysis
* Road condition analysis
* Time-based accident analysis
* Contributing factor identification

### Outcome

Identified accident trends, peak accident hours, weather-related risks, and major contributing causes of traffic accidents.
